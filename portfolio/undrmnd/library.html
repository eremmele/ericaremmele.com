Foundations / Overview

A library, not a design system for growth.

Most design systems optimize for GTM andconversion. This one optimizes for attention that leaves the screen. undrmnd translates the physical e‑ink reader paperwhite grain, finite pages, no urgency chrome — into interface so reading stays calm and contribution stays honest.

The context layer has a public URL. Humans browse it — including the annotated breakpoint spec with type labels and measures. Agents load DESIGN.md and library/tokens.json. Both should say the same thing.

What this is
Living context for the undrmnd site and iOS app: tokens, type, surfaces, behavioral patterns, and hard refusals.
What this is not
A component marketplace, a gamification kit, or a guide to “winning engagement.”
Foundations / Principles

North star:

  1. Lower barriers to inquiry. Anyone can ask, explore, and contribute without credentials or fear of backlash.
  2. Think freely without addiction. Finite sessions, clear stopping points, e‑ink visuals — not infinite feeds.
  3. From doomscrolling to contribution. Micro-interactions that foster curiosity and real, any-sized contributions.
  4. Beginner-friendly commons. Lived experience and “beginner” questions are assets, not liabilities.
  5. Open-source infrastructure. Forkable, adaptable, outside extractive engagement models.

The library should send you outside more often than it pulls you in.

Foundations / Color

Tokens that refuse spectacle.

Palette intent is paper, graphite, and a greenish paperwhite tint — never saturated marketing primaries. Accents are warm brown, not dopamine neon. If a color could belong on a billboard, it does not belong here.

Intent over position. Prefer names that say what a color does (ink, fog, eink) over primary / secondary. Agents and humans should pick by role, not by marketing hierarchy.

Foundations / Typography

Type that reads like a public library.

Don’t

  • Default to Inter / Roboto / system-only stacks
  • Use display type for dense UI chrome
  • Skip heading levels for visual effect
  • All-caps body copy
Foundations / Surfaces

Three climates, one climate of mind.

Every major surface should feel like paper, dusk, or a Kindle — never glass, never neon glassmorphism, never purple gradient SaaS.

Grain is atmosphere, not decoration. SVG noise sits lightly on paper and night. Fog-of-war uses dither and soft reveal edges — paper clearing, not smoke machine.

Patterns / Behavioral

Behavior is the delivery vehicle.

Visual language alone is not enough. These patterns encode the counter-algorithmic thesis in interaction.

  • 01

    Finite sessions

    Three-card loops with an explicit end. No “one more.” Stopping is part of the product, not a failure state.

  • 02

    Fog reveal

    The commons opens as people read and contribute. Spatial adjacency by topic — not chronological feed ranking.

  • 03

    Strata as object

    Knowledge units with schema (summary, source, relations, prompts, field notes) — not posts optimized for engagement.

  • 04

    Friction as feature

    Small pauses, load-more gates, reflective interrupts. Conscious opt-in to continue — never phantom urgency.

  • 05

    Field notes → outside

    Affordances that push attention into the world: sketch, notice, observe. Counter digital anhedonia on purpose.

  • 06

    AI used sparingly

    Semantic starting points and related Strata only. Not an oracle. The thinking belongs to people in the library.

  • 07

    Time-honest content

    Estimated times reflect a calm read. No streaks, karma, leaderboards, or false scarcity. Citations must be real.

  • 08

    One job per section

    On marketing surfaces: one purpose, one headline, one short supporting sentence. Hero budget stays lean.

Patterns / Never

What we refuse to ship.

If a proposal increases time-on-app without increasing inquiry or contribution quality, reject it.

  • Infinite scroll without an explicit gate
  • Streaks, badges-for-completion, leaderboards, “one more for free”
  • Phantom notifications, fake urgency, intermittent variable rewards
  • Autoplay by default; pull-to-refresh without friction
  • Engagement-maximizing ranking without user control
  • Vibrant dopamine palettes, glow effects, pill clusters, stat strips
  • Cards in the hero; floating promo badges on media
  • AI that decides what users should wonder about
  • Tracking SDKs; analytics that leave the device without consent
  • Fabricated DOIs, sources, or scarcity

Context / Agents

Context you can hand to an agent.

This page is the human browse surface. For Cursor, Claude, and other agents, load the machine-readable sources first — then reason across them instead of inventing a louder palette.

Primary DESIGN.md Intent, surfaces, patterns, refusals — prose an agent can follow. Tokens tokens.json Named colors, type roles, and usage hints as structured data. CSS styles.css Live :root tokens and component styles on this site. App undrmnd repo ↗ Product brief, content rubric, and Swift theme mirror.

Agent checklist

  1. Does this protect attention, or extract it?
  2. Is the stopping point visible?
  3. Would this still feel like e‑ink / paper if you removed the brand name?
  4. Are you using intent-named tokens (ink, eink) rather than inventing new hues?
  5. Would a public library put this on a quiet wall — or on a casino floor?

Mirror docs in the app repo: docs/undrmnd-product-brief.md, docs/CONTENT_RUBRIC.md, and .cursorrules. When site and app disagree, prefer the product brief + this library over legacy pattern names.

# undrmnd-site
Companion site for **undrmnd**, the open-source iOS App. Start here to learn what it is.

This repository holds the lightweight web presence for the project: a small public-facing site that introduces undrmnd, offers context for the work, and points visitors toward the main open-source app repository.

**Design library** (tokens, patterns, agent context): [library.html](./library.html) · [DESIGN.md](./DESIGN.md) · [library/tokens.json](./library/tokens.json)


## About undrmnd

undrmnd is a public learning commons, designed to be created by the people, for the people. For good-measure, and to combat digital anheonia, it's intentionally counter-algorithmic, too. 

It is an experiment in building a different kind of digital environment. Think: a digital library, or a personalized Wikipedia. It's what you make of it, and it's only alive with your contributions. Contribute, change the subject, or fork the entire repo (but not this one, this is just the marketing site).
